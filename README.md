# AgroEdge

Agricultural platform prototypes and project documents from Jay-deane Huni’s AgroEdge work.

## Explore

- `platform/` — the custom platform rebuild, including dashboard, mobile, services and shared contracts.
- `platform/development-snapshots/` — separate local development versions retained from earlier working copies.
- `original-mvp-and-documents/` — the earlier Next.js prototype and project PDFs.

Read each version’s own README before running it. The earlier Next.js prototype uses mock farm data and demonstration authentication. The platform rebuild’s original README describes it as pre-production. Historical plans, investor materials and proposed features are project records, not independent evidence of current operations, funding, live integrations or validated outcomes.

Credentials, local databases, downloaded dependencies and Git internals are excluded. See `PUBLICATION.md` for the publication scope.
