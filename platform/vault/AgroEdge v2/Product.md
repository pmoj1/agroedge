# Product

## Current state
Working Bubble MVP (app ID: agroedge-v2), demo-ready. Includes farm profiles, income/expense logging, P&L, yield tracking, analytics/reporting, and a foundational AI assistant.

Domain agroedge.co is live (Wix DNS, hosted on Bubble Starter plan).

**Known bug:** data not saving across all forms — likely owner_user not set on record creation, privacy rules, or login state during testing. Needs follow-up.

## Migration
Moving from Bubble to a custom full-stack build, in-house (Jaydeane + Aone, no agency). Repo: `AgroEdge-V2/agroedge-platform` on GitHub.

- Jaydeane's lane: `apps/` (frontend)
- Aone's lane: `services/`, `db/`, `packages/` (backend, API, database)

## AI integration (planned)
Anthropic API via Bubble API Connector (server-side only). Model routing: Haiku for routine queries, Sonnet for complex agronomy reasoning. Cost management is critical given the free-to-farmer model.

## Brand note
Confirmed brand name is "AgroEdge." In-app labeling still shows "AgriAI"/"AgriEdge" — known discrepancy, to be renamed.
