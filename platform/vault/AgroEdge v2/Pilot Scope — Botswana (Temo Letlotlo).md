# Pilot Scope — Botswana (Temo Letlotlo)

> One-page pilot definition for the **Temo Letlotlo value-add layer**, Botswana. Numbers marked *illustrative* — confirm with the Ministry and your cost model before sending.
> 

## Objective

Prove, in one season and one district, that an AI intelligence layer on top of the Temo Letlotlo Crop Management System (CMS) (1) helps farmers make better decisions and (2) gives the Ministry usable outcome data it doesn't get today.

## Scope

| Item | Proposal *(illustrative)* |
| --- | --- |
| Geography | 1 arable district |
| Crop focus | 1 priority crop (e.g. maize or sorghum) |
| Farmers | ~500–1,000 already-registered Temo Letlotlo farmers |
| Duration | 1 cropping season |
| Delivery | Through existing extension officers; AgroEdge trains and supports |

## What we deliver

- Farmer onboarding from CMS data
- Activity, expense and income logging per farmer
- Dashboards + AI insights (cost optimisation, profitability, productivity, alerts)
- A Ministry dashboard: participation + baseline→outcome data
- An end-of-pilot impact report

## Success metrics

| Metric | Target *(illustrative)* |
| --- | --- |
| Farmers logging at least weekly | 60% |
| Farmers who find insights useful (survey) | ≥70% |
| Baseline→outcome cost/income captured | ≥80% of farmers |
| Extension-officer adoption | All pilot officers active |
| Clean outcome dataset delivered to Ministry | Yes |

## Timeline (one season)

| Phase | Weeks *(illustrative)* |
| --- | --- |
| Setup & CMS integration | 1–3 |
| Extension-officer training | 3–4 |
| Farmer onboarding | 4–6 |
| Active-season logging | Across the season |
| Analysis & impact report | Final 2–3 weeks |

## What we need from the Ministry

1. Endorsement + CMS data access (within Botswana's data-protection rules)
2. The pilot district + an introduction to extension leadership
3. Pilot funding *(from cost model)*
4. A named Ministry counterpart

## Risks & mitigations

- **Connectivity gaps** → offline-capable / officer-assisted logging
- **Low farmer turnout** → work through trusted extension officers; keep logging minimal
- **Data rules** → comply with Botswana data protection; sign a data-sharing MOU
- **Government transition (Oct 2024)** → frame the pilot as helping the current administration deliver Temo Letlotlo's commercialisation goals
