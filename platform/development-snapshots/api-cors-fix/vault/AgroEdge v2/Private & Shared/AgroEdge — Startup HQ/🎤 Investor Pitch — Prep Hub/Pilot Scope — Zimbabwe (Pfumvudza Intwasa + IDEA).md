# Pilot Scope — Zimbabwe (Pfumvudza/Intwasa + IDEA)

> One-page pilot definition for the **Pfumvudza/Intwasa + IDEA value-add layer**, Zimbabwe. Donor-funded route. Numbers marked *illustrative* — confirm with the Ministry / funding partner and your cost model.
> 

## Objective

Prove, in one season and one province (or value chain), that an AI intelligence + credit-readiness layer on top of the IDEA registry and Pfumvudza/Intwasa scheme (1) helps farmers make better decisions and (2) gives the Ministry real visibility into input use and outcomes.

## Scope

| Item | Proposal *(illustrative)* |
| --- | --- |
| Geography | 1 province **or** 1 value chain |
| Farmers | ~1,000 Pfumvudza / IDEA-registered farmers |
| Duration | 1 cropping season |
| Delivery | Through AGRITEX extension officers; AgroEdge trains and supports |
| Integration | Interoperable with the IDEA farmer registry |

## What we deliver

- Farmer onboarding from IDEA / Pfumvudza records
- Activity, expense and income logging per farmer
- Dashboards + AI insights (cost, profitability, productivity, pest alerts)
- Loan / insurance-readiness scoring from accumulated farm data
- A Ministry dashboard: input-use transparency + baseline→outcome data
- An end-of-pilot impact report

## Success metrics

| Metric | Target *(illustrative)* |
| --- | --- |
| Farmers logging at least weekly | 60% |
| Farmers who find insights useful (survey) | ≥70% |
| Baseline→outcome cost/income captured | ≥80% of farmers |
| Input-use transparency report to Ministry | Delivered |
| AGRITEX officer adoption | All pilot officers active |

## Timeline (one season)

| Phase | Weeks *(illustrative)* |
| --- | --- |
| Setup & IDEA integration | 1–3 |
| AGRITEX officer training | 3–4 |
| Farmer onboarding | 4–6 |
| Active-season logging | Across the season |
| Analysis & impact report | Final 2–3 weeks |

## What we need

1. Ministry endorsement + interoperability with the IDEA registry
2. Introduction to the funding partner (AfDB / FAO) for pilot funding
3. AGRITEX engagement in the pilot province
4. A named Ministry counterpart

## Risks & mitigations

- **Connectivity gaps** → offline-capable / officer-assisted logging
- **Currency / funding instability** → secure donor (not Treasury) funding; price in stable currency
- **Registry fragmentation** → integrate with IDEA; keep tobacco/other registries out of pilot scope
- **Low turnout** → deliver through trusted AGRITEX officers; keep logging minimal
